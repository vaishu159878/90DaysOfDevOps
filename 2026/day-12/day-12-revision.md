## 1. Which 3 commands save you the most time right now?

systemctl status
ps aux
ls -l

These commands help quickly find Linux issues.

## 2. How do you check if a service is healthy?

systemctl status nginx
ps aux | grep nginx
journalctl -u nginx

3. How do you safely change ownership and permissions?
sudo chown ubuntu:ubuntu notes.txt
chmod 755 notes.txt

This safely changes ownership and provides proper access permissions.
