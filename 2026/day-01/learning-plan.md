# 90 Days of DevOps – Learning Plan

## Current Level
I am a student and currently starting my DevOps and Cloud learning journey from beginner level. I have basic knowledge of computers and technology, and now I want to build practical DevOps skills through consistent learning and hands-on practice.

## My Understanding of DevOps & Cloud Engineering
DevOps is a culture and set of practices that help developers and operations teams work together efficiently by automating software development, testing, deployment, and monitoring.

Cloud Engineering is about building, deploying, and managing applications using cloud platforms like AWS to make systems scalable, reliable, and efficient.


## Why I Am Learning DevOps & Cloud
I am starting DevOps because I want to build a strong career in cloud and automation technologies. I want to gain practical skills that are used in real companies and become confident in handling deployments, infrastructure, and CI/CD pipelines.

I also want to improve my problem-solving skills, technical communication, and hands-on experience through projects and daily practice.


## My Goals for the Next 90 Days
1. Learn Linux, Git, Docker, AWS, Kubernetes, Terraform, and CI/CD fundamentals.
2. Build and deploy real DevOps projects using Docker, Jenkins, and Kubernetes.
3. Create a strong GitHub and LinkedIn profile by sharing my learning journey publicly.



## Core DevOps Skills I Want to Build
1. Linux troubleshooting and command-line skills
2. CI/CD pipeline creation and automation
3. Docker and Kubernetes deployment/debugging



## Weekly Time Commitment
- Weekdays: 2–3 hours daily
- Weekends: 4–6 hours daily
- Daily focus: Learning + Hands-on Practice + Notes



## How I Will Stay Consistent
- Follow the challenge daily without skipping tasks
- Practice commands and projects instead of only watching videos
- Share progress on LinkedIn and GitHub regularly
- Revise previous topics every weekend
- Stay disciplined even on difficult days



## My Target After 90 Days
By the end of this challenge, I want to become confident in DevOps fundamentals, build multiple hands-on projects, and prepare myself for internships and entry-level DevOps opportunities.
