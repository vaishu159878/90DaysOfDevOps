# Day 03 – Linux Commands Practice 🐧

## 📘 Objective

Today’s goal was to build confidence with essential Linux commands used in real-world troubleshooting and DevOps environments.

The focus areas included:
- File system management
- Process management
- Networking troubleshooting
- System monitoring

---

# 📂 File System Commands

Command &  Usage 

pwd = Show current working directory 
ls -la = List all files with details 
cd <dir> = Change directory 
mkdir <dir> = Create new directory 
touch file.txt = Create empty file 
cp file1 file2 = Copy files 
mv old new = Move or rename files 
rm file.txt = Remove file 
find / -name file.txt = Search files 
cat file.txt = Display file contents 

---

# ⚙️ Process Management Commands

 Command & Usage 

ps aux = Show running processes
top = Monitor live processes 
htop = Interactive process viewer 
kill <PID> = Stop running process 
free -h = Show memory usage 

---

# 🌐 Networking Commands

  Command & Usage 

ping google.com = Test network connectivity 
curl https://example.com = Send HTTP request 
ifconfig = Show network configuration 
netstat = View network connections 
hostname -I = Show system IP address 

---

# 📜 System & Utility Commands

 Command & Usage 

df -h = Check disk space usage 
uname -a = Show system information 
uptime = Show system uptime 
history = View command history 
date = Show current system date and time
